Build Your Own Agents

Build your own Agents 自己的助理自己做 · Microsoft 365 Copilot

Step 01

認識 Agent

用指令決定它怎麼做，用知識決定它能看什麼。

01
Agent 是 AI 助手，通過預先定義的指令、限定範圍的知識來為使用者執行任務。

目的 Purpose

這個 Agent 是什麼、要達成什麼目標。

指引 Guidelines

基本指示、語氣、規則與限制。

技能 Skills

具分步工作流程的精細任務，可由 LLM 處理。

Step 02

開始建立

由 Microsoft 範本建立，或從頭建立。

02

從範本建立

範本先帶好設定，你只要微調。

從頭開始

用三句指令，讓 Builder 生成描述與指示詞。

Step 03

加入知識

用知識庫限制答案依據。

03

文件

加入要參考的文件，回答只依據這些內容。

Teams 對話

指定特定聊天室，讓 Agent 讀得到討論脈絡。

Web Search

需要即時公開資訊時再開啟。

沒有加入知識，Agent 只能依一般知識回答；加入知識後，答案就有明確依據。

從範本建立

範本先帶好設定，你只要微調。

A

1. 選擇模板

挑最接近需求的範本，名稱、描述與指示詞會自動帶入。

2. 名稱與描述

用三句話說明它要做什麼，Builder 自動生成描述與指示詞。

3. 知識庫

指定文件或 Teams 對話當依據；需要即時資訊再開 Web Search。

4. 預設回答

放入常用問題，使用者一點就能開始。

5. 測試優化

從「設定」切到「預覽」，問一個真實問題，確認格式後再調整。

6. 建立

確認名稱、描述、指示詞與知識來源，按「建立」即可使用。

從頭開始

用三句指令，讓 Builder 生成描述與指示詞。

B

1. 不使用範本

不使用範本，直接從設定頁建立 Agent。

2. 名稱與描述

填寫 Agent 名稱與描述，再用「下一步」繼續。

3. 指示詞與知識

完成指示詞，再加入企業知識作為回答依據。

4. 建議提示詞

加入 Starter prompt，讓使用者一點就能開始。

5. 測試優化

從「設定」切到「預覽」，問一個真實問題，確認格式後再調整。

6. 建立

預覽確認後，按「建立」即可使用。

Done

你的專屬助理

建立完成，直接開始用它工作。
